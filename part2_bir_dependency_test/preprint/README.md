# preprint/ — retained as documentation, not an active plan

**No preprint is being written.** The result does not warrant formal publication, and that
decision was taken deliberately rather than by default.

These four files were drafted before that decision and are kept because they are useful as
documentation in their own right: the outline is the clearest single statement of what the
project found and in what order, and the figure plan maps each display item to the committed
CSV that holds its numbers. Treat them as a structured summary, not as work in progress.

| File | What it is |
|---|---|
| `draft_outline.md` | Section-by-section outline; §3 is the construct post-mortem |
| `key_figures.md` | Figure and table plan, each item traced to its source file |
| `abstract_draft.md` | A 151-word abstract draft |
| `references.bib` | DOI-keyed skeleton. **DOIs, journals and years are verified; titles and author lists are placeholders** and are marked as such in the file header. |
